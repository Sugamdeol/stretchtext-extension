ST Stretchtext

Text that grows where you want more.

In 1967 Ted Nelson described stretchtext: prose that opens up one phrase at a time, so detail appears exactly where your attention is. Writing every level by hand was too much work, so it never caught on. Generated text makes it cheap.

Stretchtext brings that to any web page. Hover a paragraph, press Expand, and the text grows in place — same element, same page, no modal, no new tab. Shrink condenses it back. You pay with your own Pollen; there is no shared key.

Install it

Option 1 — download the zip

  1. Download extension.zip and unpack it (it contains a single extension/ folder).
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked and choose the extension/ folder.

Option 2 — from source

  1. Clone the repository.
  2. Open chrome://extensions → Developer mode.
  3. Load unpacked → select the repo's extension/ directory.

There is nothing to build. The extension/ directory is the extension.

How it works

1

Hover a paragraph

A small control appears right above it. Select text inside a paragraph and the same control focuses that paragraph.

2

Click Expand

Pollinations rewrites the block with more detail — concrete specifics, context, mechanism. It lands in the same element, so the page layout is untouched.

3

Shrink it back

Condense it again, or hit Restore to return the exact original wording. Keyboard: Alt+E and Alt+S.

Your own Pollen

Stretchtext uses the Pollinations OAuth device flow, the one the API docs recommend for extensions. The popup's Sign in with your own Pollen button shows a short code, opens the verification page, and waits for your approval.

  • Your key is stored in chrome.storage.local only — never in a web page, never in a URL, never logged.
  • All API calls run in the extension's service worker, so your key never reaches a page's JavaScript.
  • The popup shows your Pollen balance, and the in-page control shows what the rewrites on the current page have cost.

Permissions, and why

Permission Why it is needed
storage Holds your Pollen key and the verbosity preference, in chrome.storage.local only.
gen.pollinations.ai The text API and the balance endpoint.
enter.pollinations.ai Device-flow sign-in and user info.
Content script on http(s)://* It has to read the text of the page you are reading to rewrite that one block in place. Nothing leaves the page until you click.
